# 06. PREMIUM MOTION DESIGN SYSTEM

Bangun reusable motion system, bukan animasi terpisah tanpa standar.

## 6.1 Motion tokens

Definisikan reusable tokens untuk:

- Duration.
- Easing.
- Entrance distance.
- Stagger.
- Hover response.
- Layout transition.
- Modal transition.
- Page section reveal.

Contoh pendekatan:

- Micro interaction: sekitar 120–220 ms.
- Standard transition: sekitar 200–400 ms.
- Editorial reveal: sekitar 450–800 ms.

Angka merupakan titik awal dan harus disesuaikan berdasarkan pengujian.

## 6.2 Motion categories

### Micro-interaction

Untuk:

- Buttons.
- Tabs.
- Cards.
- Toggle.
- Selectors.
- Form states.

### Scroll storytelling

Untuk:

- Section introductions.
- Product imagery.
- Feature reveals.
- Workshop process.

### Spatial transitions

Untuk:

- Configurator preview.
- Product switching.
- Modal gallery.
- Mobile navigation.

### Ambient effects

Untuk:

- Subtle mirror lighting.
- Controlled glow.
- Background atmospheric movement.

## 6.3 Motion constraints

Dilarang:

- Continuous heavy animation pada semua section.
- Scroll-jacking.
- Layout thrashing.
- Excessive blur filters.
- Excessive parallax.
- Animasi yang menghalangi CTA.
- Animasi loading yang menunda interaksi.
- Animasi dekoratif yang mengganggu form.

Hormati reduced-motion preference.

Animasi tidak boleh menjadi dependency agar website dapat digunakan.

# 10. PERFORMANCE ENGINEERING

Targetkan Core Web Vitals yang baik untuk pengguna nyata.

Target evaluasi p75 mobile:

- LCP ≤ 2.5 detik.
- INP ≤ 200 ms.
- CLS ≤ 0.1.

Target Lighthouse mobile ≥ 90 pada kategori utama yang relevan, jika realistis berdasarkan kondisi deployment dan third-party scripts.

Target tersebut merupakan sasaran pengujian, bukan angka yang boleh diklaim tanpa pengukuran.

## 10.1 JavaScript optimization

Lakukan:

- Bundle analysis.
- Remove unused dependencies.
- Client component boundary optimization.
- Code splitting.
- Deferred non-critical scripts.
- Lazy-load non-critical interactive modules.
- Reduce unnecessary state updates.
- Avoid hydration mismatches.

Perhatikan configurator existing yang memiliki kompleksitas tinggi.

Refaktor secara terukur tanpa kehilangan fitur.

## 10.2 Image optimization

- Gunakan asset real yang tersedia.
- Pertahankan responsive srcset jika efektif.
- Optimalkan format dan ukuran.
- Hindari image distortion.
- Tetapkan image dimensions untuk mencegah CLS.
- Prioritaskan hero/LCP image.
- Lazy-load below-the-fold image.
- Sesuaikan dengan static export architecture.

## 10.3 Font optimization

- Self-host bila tepat.
- Gunakan font subsets.
- Batasi jumlah font weights.
- Gunakan font-display strategy yang tepat.
- Preload hanya asset kritis.
- Hindari FOIT.

## 10.4 CSS optimization

- Remove unused styles.
- Consolidate tokens.
- Limit expensive paint operations.
- Use transforms for animations.
- Avoid unnecessary filters and shadows.

Lakukan perbandingan baseline dan hasil akhir.

Jangan hanya menyebut website lebih cepat tanpa hasil pengukuran.
